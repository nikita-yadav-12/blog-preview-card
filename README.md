### What I learned

- **Project workflow:** I learned how to build a project step by step, starting with the HTML structure, adding CSS styles, making the layout responsive, and testing it against the design.
- **Flexbox:** I learned how to use Flexbox to manage the page layout and keep the footer at the bottom of the page without using fixed positioning.
- **Responsive design:** I learned how to make the blog card responsive for smaller screen sizes using `rem` units and media queries.
- **Git:** I learned how to use Git to track my progress, create meaningful commits at different stages, and manage changes while building a project.
